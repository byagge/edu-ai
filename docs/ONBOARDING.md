# Настройка новой клиники за 3–4 часа

Цель из ТЗ §11: от «есть клиент» до «пилот пошёл» без правок кода.

## 0. Что нужно от клиники (15 минут разговора)

- прайс (Excel или фото — главное, цены и длительности);
- врачи и их графики;
- адрес, часы работы, телефон, ссылка 2ГИС/Google;
- кто администратор и кто владелец (их Telegram);
- номер WhatsApp и/или бот Telegram;
- 5–10 вопросов, которые пациенты задают чаще всего и которых нет в шаблоне.

## 1. Создать тенанта (2 минуты)

```bash
cd backend
python -m arix.cli create-tenant \
  --slug dental-smile-shym --name "Dental Smile" \
  --city Шымкент --country KZ --timezone Asia/Almaty \
  --languages ru,kz --template clinic_dental
```

Шаблон сразу приносит 8 типовых услуг, 3 врача с графиками, **55 типовых
вопросов** и тексты напоминаний. Для косметологии — `clinic_cosmetology`.

## 2. Импортировать прайс и врачей (30–60 минут)

```bash
python -m arix.cli import-prices --slug dental-smile-shym --file prices.xlsx
python -m arix.cli import-prices --slug dental-smile-shym --file doctors.xlsx --kind doctors
```

Колонки распознаются по нескольким вариантам названий (`услуга` / `наименование`
/ `service`, `цена от` / `цена` / `price`, `мин` / `длительность`). Импортёр
возвращает список проблем — например, «услуга без цены»: такую услугу бот
назовёт «цена уточняется» и передаст администратору, но цену не выдумает.

Проверить глазами: панель → Прайс. Там же правятся длительность, буфер,
`recall_days` и флаг «онлайн-запись» (его стоит снять с имплантации,
ортодонтии и всего, что требует консультации).

## 3. Заполнить конфиг тенанта (20 минут)

```bash
curl -X PUT "$PUBLIC_BASE_URL/admin/tenants/<id>/config" \
  -H "X-Arix-Admin-Token: $ADMIN_API_TOKEN" -H 'content-type: application/json' \
  -d '{
    "data": {
      "address": "ул. Абая 10",
      "phone": "+7 7252 00 00 00",
      "map_url": "https://2gis.kz/shymkent/firm/123",
      "working_hours": {"mon-sat": "09:00-20:00", "sun": "off"},
      "quiet_hours": "21:00-09:00",
      "reviews": {"links": {"2gis": "https://2gis.kz/...", "google": "https://g.page/..."}},
      "features": {"waitlist": false, "miniapp_payments": false},
      "agent": {"tone": "коротко, тепло, по-деловому"}
    }
  }'
```

Конфиг версионируется: каждая публикация — новая версия, откат это выбор
старой версии, а не правка истории.

## 4. Добавить сотрудников (5 минут)

```bash
curl -X POST "$PUBLIC_BASE_URL/admin/tenants/<id>/staff" \
  -H "X-Arix-Admin-Token: $ADMIN_API_TOKEN" -H 'content-type: application/json' \
  -d '{"role":"owner","name":"Владелец","tg_user_id":123456789,
       "email":"owner@clinic.kz","password":"<пароль для панели>"}'
```

Роли: `owner`, `admin`, `doctor` (для врача укажите `entity_id` — id из
`doctors`, тогда `/today` покажет его расписание).

Telegram id узнаётся через [@userinfobot](https://t.me/userinfobot).

## 5. Подключить каналы (20 минут)

```bash
python -m arix.cli connect-telegram --slug dental-smile-shym --token <BOT_TOKEN>
python -m arix.cli wa-qr --slug dental-smile-shym       # QR на телефон клиники
```

Для Telegram Business — [TELEGRAM_BUSINESS.md](TELEGRAM_BUSINESS.md).
Для WhatsApp обязательно прочитайте клиенту раздел про риски из
[WHATSAPP_BAILEYS.md](WHATSAPP_BAILEYS.md).

## 6. Добавить вопросы клиники в базу знаний (30 минут)

Панель → База знаний. Флаг «цитировать дословно» ставьте на условия возврата,
политику отмены и всё, что нельзя пересказывать своими словами.

## 7. Прогнать 20 тестовых диалогов (30 минут)

```bash
cd backend && python -m arix.eval.runner      # автоматические 64 диалога
```

Руками обязательно проверить на этой клинике:

- [ ] цена самой частой услуги совпадает с прайсом;
- [ ] предлагаются 2–3 конкретных слота, а не «когда вам удобно»;
- [ ] «болит и опухло» → текст о срочности и передача админу;
- [ ] «дайте скидку» → передача, без выдуманной скидки;
- [ ] «можно записаться на имплантацию» → передача (не онлайн-услуга);
- [ ] напоминание −24 ч приходит с кнопками;
- [ ] администратор получает карточку передачи и может «Взять»;
- [ ] утренний отчёт приходит владельцу.

## 8. Пилот

Статус тенанта → `pilot`, и первые 7 дней смотреть ежедневно:

```bash
python -m arix.cli report --slug dental-smile-shym
```

Критерии успеха пилота (ТЗ §0): первый ответ ≤ 15 сек в 95% диалогов, ≥ 60%
диалогов закрыты без человека, 0 двойных записей, 0 выдуманных цен.

Если бот часто передаёт человеку — смотрите `handoff_reasons` в
панели: `out_of_kb` значит, что в базе знаний не хватает фактов, и это
исправляется текстом, а не кодом.
