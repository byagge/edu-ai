## Главное

**Этот репозиторий — работа в процессе, запустить продукт целиком пока нельзя.**

- Скопировано ядро из `clinic-ai` (каналы, диалоговый движок, PII, планировщик, база знаний, guardrails, Telegram Business, Baileys-сайдкар). Общие юнит-тесты ядра проходят (58 тестов: guardrails, PII, время/тихие часы).
- Написана доменная часть модуля «Учебный центр» (`backend/arix/verticals/edu/`): модели, счета и лестница долгов, зачисление с блокировкой по вместимости, пробные, посещаемость, тест уровня, инструменты агента, диалоговый сценарий, таймеры, задания, отчёт владельцу. Все модули импортируются, **но не покрыты тестами и ни разу не выполнялись против базы**.
- **Не написано:** миграция БД, YAML-шаблоны центров (`edu_language` и др.), API-слой для edu (вебхуки/панель/Mini App/бот сотрудника всё ещё ссылаются на клинику, `arix.main` **не импортируется**), eval-набор, тесты вертикали, интерфейс панели для edu.

Из-за этого CI в этом репозитории временно запускает только юнит-тесты ядра.
