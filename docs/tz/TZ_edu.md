# ТЗ: ИИ-менеджер ARIX — ядро + модуль «Учебный центр»

Версия 1.0 · 19.10.2026 · для разработки в Cursor / Claude Code

## 0. Цель

Один ИИ-менеджер для учебного центра (языки и IELTS, подготовка к поступлению и ЕНТ, IT, детские развивающие). Он отвечает 24/7, подбирает курс, проводит тест уровня, записывает на пробный урок, дожимает после пробного, напоминает об оплате, сообщает родителям о пропусках, продлевает обучение и каждое утро шлёт отчёт владельцу.

Ядро то же, что у клиник (см. ТЗ «Клиника», §2–6, 8, 13–14). Если ядро уже собрано, начинай с части B. Часть A ниже — краткая выжимка, чтобы ТЗ можно было отдать отдельно.

**Критерии успеха пилота (7–14 дней):**

- первый ответ ≤ 15 сек в 95% диалогов;
- ≥ 70% заявок доходят до записи на пробный или теста уровня;
- явка на пробный ≥ 75% (напоминания + подтверждение);
- 100% должников получают напоминание по лестнице, владелец видит список долгов каждое утро;
- настройка центра по шаблону ≤ 4 часов.

## Часть A. Ядро (выжимка)

- **Стек:** Python 3.12, FastAPI, PostgreSQL 16, Redis, arq, aiogram 3; WhatsApp-адаптер (Meta Cloud API / провайдер); Claude с tool use; STT для голосовых; Mini App на React + Vite + TS.
- **Принципы:** мультитенантность (`tenant_id` + RLS), конфиг вместо кода, факты только из инструментов, идемпотентность, всё — событие.
- **Таблицы ядра:** `tenants`, `tenant_config`, `channels`, `contacts`, `conversations`, `messages`, `kb_items`, `scheduled_jobs`, `sequences`, `handoffs`, `events`, `payments`, `staff` (поля — как в ТЗ «Клиника» §4.1).
- **Конвейер:** Channel Gateway → Conversation Engine → PII Guard → Agent (LLM + tools) → Domain Services → Scheduler → боты владельца/админа.
- **Handoff:** просьба человека, конфликт, торг/скидка, вопрос вне базы, возврат денег, 2 непонятых сообщения подряд. Карточка админу в Telegram, подхват 10 мин, эскалация владельцу 30 мин.
- **Тихие часы** 21:00–09:00 для исходящих рассылок. Ответы на входящие — всегда.

## Часть B. Модуль «Учебный центр»

### B1. Чем отличается от клиники

| | Клиника | Учебный центр |
|---|---|---|
| Единица записи | слот врача (время × длительность) | место в группе (вместимость) + пробный урок |
| Кто пишет | сам пациент | родитель (платит) и ученик (учится) |
| Деньги | разово за визит | ежемесячно, долги, продления |
| Повтор | recall через 6 мес | продление каждый месяц, следующий уровень |
| Сезон | ровно | пики: сентябрь, январь, лето (интенсивы), перед экзаменами |
| Главная утечка | неявки | пробный → оплата (на перегретом рынке 10–20%) |

### B2. Роли

| Роль | Где | Что делает |
|---|---|---|
| Родитель | WA / TG / Mini App | спрашивает, записывает ребёнка, платит, получает отчёты и уведомления о пропусках |
| Ученик (взрослый или подросток) | TG / Mini App | тест уровня, расписание, ДЗ, баланс (если сам платит) |
| Администратор | бот «Админ», веб | заявки, пробные, оплаты вручную, перенос групп |
| Преподаватель | бот «Учитель» | отметка посещаемости за 1 тап, ДЗ, оценка, «урок отменён» |
| Владелец | бот «Владелец» | утренний отчёт, долги, наполненность групп, риск ухода |

### B4. Инструменты агента

| Инструмент | Что делает |
|---|---|
| `kb_search` | факты из базы (адрес, условия, возврат, документы) |
| `match_course` | по возрасту, цели, уровню, времени → 1–3 курса и группы |
| `list_groups` | группы курса с расписанием, ценой, свободными местами |
| `start_level_test` / `submit_answer` | тест уровня в чате, кнопками |
| `book_trial` | запись на пробный (место в группе или отдельный слот) |
| `enroll` | бронь места в группе, создание enrollment и первого счёта |
| `create_payment_link` | ссылка Click / Payme / Kaspi на счёт |
| `get_balance` | счета и долги ученика (только родителю-плательщику или самому взрослому ученику) |
| `add_to_waitlist` | лист ожидания на курс или время |
| `handoff` | передача человеку |

**Правила агента (дополнительно к ядру):**

- Не обещать баллы IELTS / ЕНТ / вступительных и «гарантированное поступление». Только факты из базы: программа, часы, кейсы, если они есть в KB.
- Условия оплаты, рассрочки и возврата озвучивать только из KB, дословно. Спор о возврате → handoff.
- С несовершеннолетними: данные ребёнка собираем через родителя. Отчёты об учёбе шлём только контакту из `guardians`.
- На просьбу «дешевле» → handoff (торг решает человек), не выдумывать скидки.

### B5. Сценарии и критерии приёмки

**У1. Заявка → подбор.** «Сколько стоит английский для ребёнка 10 лет?» → уточнить уровень/цель → `match_course` → 1–2 группы с ценой и временем + предложение пробного или теста. Приёмка: цена совпадает с курсом, предложены конкретные даты.

**У2. Тест уровня.** 12–15 вопросов кнопками (грамматика, лексика, чтение), 5–7 минут. Итог: уровень + подходящая группа + запись на пробный. Результат уходит админу. Для детских направлений вместо теста — анкета из 4–5 вопросов.

**У3. Пробный урок.** `book_trial` → подтверждение, адрес, что взять с собой. Напоминания −24 ч (кнопки «Придём / Перенести») и −2 ч. Нет ответа → задача админу позвонить.

**У4. Дожим после пробного.** Учитель за 1 тап ставит оценку пробного и короткую заметку. Через 1–2 ч родителю: впечатление учителя + рекомендованная группа + «места: осталось N» + ссылка на оплату. +1 день, +3 дня — разные тексты. Стоп при оплате, отказе или ответе. Неявка на пробный → через 1 ч предложить новую дату.

**У5. Набор группы.** Группа со статусом `recruiting` и `min_to_start`. Когда набрано минимальное число, все записавшиеся получают дату старта. Если набора нет к дате — предложить другую группу или лист ожидания.

**У6. Оплата и долги.** Счёт создаётся в `billing_day`. Лестница: −3 дня (ссылка), день оплаты, +3 дня, +7 дней (мягко), +10 дней → handoff админу, в утренний отчёт. Оплата через Click/Payme/Kaspi закрывает счёт по вебхуку. Наличные/перевод — админ отмечает кнопкой.

**У7. Посещаемость.** За 10 мин до конца урока учителю приходит список группы, он отмечает отсутствующих (остальные — «был»). Пропуск → сообщение родителю в тот же день. 2 пропуска подряд или 3 за месяц → флаг «риск ухода» → админу и в отчёт.

**У8. Отчёт родителю (v2).** Раз в месяц: посещаемость, оценки и комментарий учителя (1–2 строки), что дальше. Для взрослых — короткая сводка.

**У9. Продление и следующий уровень.** За 7 дней до конца оплаченного периода — напоминание. За 2 недели до конца уровня — предложение следующего уровня/курса с датой старта.

**У10. Реферальная программа (v2).** Каждому активному ученику — личная ссылка. Пришёл друг и оплатил → награда (например, месяц бесплатно — из конфига). Статистика в отчёте.

**У11. Отмена/перенос урока.** Учитель или админ нажимает «урок отменён/перенесён» → все родители и ученики группы получают сообщение за ≤ 1 мин.

**У12. Отзывы.** Через 30 дней обучения — оценка 1–5. 5 → ссылка на 2ГИС / Google. 1–3 → владельцу.

**У13. Реактивация.** Ушедшие ученики (`left`) раз в сезон (август, декабрь) получают предложение нового набора — только с маркетинговым согласием.

**У14. Утренний отчёт владельцу (08:00).** Пример:

```
Вчера, 18 окт · Bright English Самарканд
Заявок 23 · ответили за 8 сек
Пробных назначено 9 · пришли 7 · оплатили 3 (43%)
Группы: IELTS-вечер 7/10, Kids A1 10/10, General B1 4/8 (не набрана)
Долги: 6 учеников · 3 400 000 сум · дольше 10 дней: 2 → позвонить
Риск ухода: Азиз Р. (2 пропуска), Мадина К. (3 пропуска за месяц)
Оплаты через Mini App: 7 200 000 сум
```

### B7. Mini App (опция)

- Родитель/ученик: расписание, ближайший урок, баланс и счета, оплата, посещаемость, ДЗ, результаты теста, реферальная ссылка.
- Новый клиент: курсы, цены, тест уровня, запись на пробный.
- Учитель: мои группы сегодня, посещаемость, ДЗ.
- Платежи: UZ — Click и Payme (для автосписаний — Payme Subscribe API с токенизацией карты, v3); KZ — Kaspi (через посредника) и карта.
- Атрибуция выручки для «Доли»: `miniapp`, `trial_followup`, `reactivation`, `referral`.

### B8. Импорт и интеграции

- **Модуль работает без внешней CRM:** своя база групп, учеников и счетов.
- **Импорт** из Excel/Google Sheets: ученики, родители, группы, долги (шаблон колонок в панели).
- **Modme (UZ):** публичного API не нашли — уточнить у Modme. До этого — импорт/экспорт Excel раз в день или двусторонняя сверка вручную.
- **AlfaCRM (KZ/RU):** есть REST API → адаптер синхронизации клиентов, групп, уроков, оплат (v3).
- **KZ, единый ваучер на допобразование (пилот в Шымкенте):** бот объясняет родителям, как выбрать центр по ваучеру, если центр — поставщик (тексты в KB). Интеграция с платформой ваучера — не сейчас.

### B9. Настройка центра за 3–4 часа

Шаблоны: `edu_language.yaml`, `edu_exam_prep.yaml`, `edu_kids.yaml`, `edu_it.yaml` — с типовыми вопросами (40–60), тестом уровня (для языков), текстами лестницы оплат и дожима на RU / UZ / KZ.

```yaml
tenant: bright-english-smq
vertical: edu
template: edu_language
country: UZ
city: Самарканд
timezone: Asia/Samarkand
languages: [uz, ru]
billing:
  mode: monthly          # monthly | per_lesson | course
  billing_day: by_start  # by_start | fixed:1
  ladder_days: [-3, 0, 3, 7, 10]
trial:
  free: true
  followup_hours: [2, 24, 72]
referral:
  reward: "1 месяц бесплатно"
features:
  level_test: true
  attendance: true
  parent_reports: false
  miniapp_payments: false
review_links: {2gis: "https://2gis.uz/...", google: "https://g.page/..."}
imports: [courses.xlsx, groups.xlsx, students.xlsx]
```

### B10. Безопасность

- Данные детей — только через родителя, согласие родителя при первой записи.
- Минимум данных: имя ребёнка, год рождения, уровень, контакт родителя. Не собираем документы и школу без необходимости.
- UZ: с поправок 2026 года обязательная локализация — для биометрии и генетики; мы их не собираем. KZ: хранение ПД в РК для KZ-тенантов (как в ТЗ «Клиника» §13).
- Маскирование ПД перед LLM, удаление по запросу.

### B11. Тестирование

- Eval из 60 диалогов (RU/UZ/KZ): подбор курса, тест уровня, запись на пробный, торг, «гарантируете 7.0?», возврат денег, родитель спрашивает про чужого ребёнка, промпт-инъекции.
- Приёмка: 0 обещаний баллов/поступления, 0 выдуманных цен и скидок, 0 утечек данных другого ученика, 100% handoff на возврат и торг.
- Юнит-тесты: генерация счетов (дата старта посреди месяца, скидки, пауза), лестница долгов, вместимость групп, тихие часы.
