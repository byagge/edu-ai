# WhatsApp без оплаты Meta: Baileys

## Зачем

У Meta Cloud API две проблемы для небольшой клиники:

1. **Деньги.** С 01.10.2026 сервисные сообщения сверх бесплатной квоты платные,
   у Казахстана отдельный тариф. Напоминание «ждём вас завтра в 10:00» — это
   платное сообщение, и на 300 визитах в месяц счёт становится заметным.
2. **Шаблоны.** Вне 24-часового окна можно отправить только заранее одобренный
   шаблон. Каждый новый текст — заявка на модерацию, на трёх языках.

`waweb/` — сайдкар на Node, который говорит по протоколу WhatsApp Web
(multi-device) через библиотеку Baileys. Клиника один раз сканирует QR своим
обычным номером, и дальше сообщения ходят без платы за сообщение и без
шаблонов.

## Как это работает

```
Пациент ──WhatsApp──▶ номер клиники ──Baileys──▶ waweb
                                                   │  POST /webhooks/wa/baileys/<slug>
                                                   │  подпись HMAC-SHA256
                                                   ▼
                                                backend ──▶ агент ──▶ ответ
                                                   │  POST /sessions/<slug>/messages
                                                   ▼
                                                 waweb ──▶ WhatsApp
```

- одна сессия на тенанта, учётные данные в `/data/sessions/<slug>` (том);
- `connection.update`, `qr` и `logout` прилетают в бэкенд и меняют статус
  канала, поэтому в панели сразу видно «отвалилось»;
- доставка вебхука с ретраями (бэкенд дедуплицирует по id сообщения, так что
  повтор безопаснее потери);
- бэкенд → сайдкар по bearer-токену (`WA_BAILEYS_TOKEN`), сайдкар → бэкенд по
  HMAC (`WA_WEBHOOK_SECRET`).

## Чем мы снижаем риск бана

Это неофициальный клиент, поэтому в код встроены ограничения, а не надежда:

| Механизм | Где | Зачем |
|---|---|---|
| пауза между сообщениями (по умолчанию 1.2 с) | `waweb/src/session.js` | не выглядеть как бот-рассыльщик |
| лимит сообщений в минуту (по умолчанию 20) | там же | срезать пики |
| очередь на сессию | там же | сохранять порядок в чате, не отправлять параллельно |
| индикатор «печатает» | там же | темп, похожий на человеческий |
| группы и статусы игнорируются | там же | не отвечать там, где нас не ждут |
| тихие часы 21:00–09:00 для исходящих | `scheduler/jobs.py` | не писать ночью |
| маркетинг только с отдельным согласием | `domain/messaging.py` | «давно не были» уходит только по `consent_marketing_at` |
| «стоп» отключает рассылки мгновенно | `agent/runtime.py` | снижает жалобы, а жалобы и есть причина банов |

Чего мы **не** делаем и не будем: массовых рассылок по купленным базам,
отправки первым незнакомым номерам, нескольких номеров с одного сервера для
обхода лимитов.

## Что сказать клиенту прямо

- Это не официальный API. WhatsApp может разлогинить устройство или
  заблокировать номер, если жаловаться будут пациенты.
- Поэтому: только ответы тем, кто написал сам, и напоминания тем, кто записан.
- Если клиенту нужен официальный канал (крупная сеть, тендерные требования),
  в системе есть `WA_PROVIDER=cloud_api` — тот же интерфейс, но Meta,
  шаблоны и счётчик платных сообщений с алертом на 80% квоты.
- Номер лучше брать отдельный рабочий, не личный телефон владельца.
- Том `wasessions` — это и есть «залогиненность». Потеряете том — нужно
  сканировать QR заново.

## Подключение

```bash
make up
cd backend && python -m arix.cli wa-qr --slug <slug>   # или панель → Каналы
```

На телефоне: WhatsApp → Настройки → Связанные устройства → Привязать
устройство. Статус в панели станет `connected`.

## Переключение на Cloud API

```bash
curl -X POST "$PUBLIC_BASE_URL/admin/tenants/<tenant_id>/channels/whatsapp" \
  -H "X-Arix-Admin-Token: $ADMIN_API_TOKEN" -H 'content-type: application/json' \
  -d '{"mode":"cloud_api","phone_number_id":"...","access_token":"...",
       "app_secret":"...","verify_token":"..."}'
```

Вебхук: `POST /webhooks/wa/cloud/<slug>` (верификация — `GET` с
`hub.verify_token`). Вне 24-часового окна бэкенд не отправит свободный текст:
без шаблона сообщение не уйдёт и будет записано как `outside_window_no_template`,
чтобы это было видно, а не «потерялось».

## Диагностика

```bash
curl localhost:3001/health                       # статусы всех сессий
docker compose logs -f waweb
docker compose exec backend python -c "
import asyncio
from arix.channels.whatsapp import BaileysAdapter
print(asyncio.run(BaileysAdapter('<slug>').health()))"
```

| Симптом | Причина | Что делать |
|---|---|---|
| `status: logged_out` | устройство отвязали на телефоне | сканировать QR заново |
| `not_connected` при отправке | телефон офлайн или сессия поднимается | подождать, сайдкар переподключается сам |
| QR не появляется | сессия ещё стартует | повторить запрос через 2–3 секунды |
| вебхуки не доходят | не совпал `WA_WEBHOOK_SECRET` | сверить значение в обоих сервисах |
